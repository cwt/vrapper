# Bug 10 — `SubwordMotion` uses stale `fromPosition` on multi-step calls and throws on EOF

**File:** [`SubwordMotion.java`](../../plugins/net.sourceforge.vrapper.plugin.subwordtextobj/src/net/sourceforge/vrapper/plugin/subwordtextobj/commands/SubwordMotion.java#L78-L101) [^src-1]
**Upstream Issue:** [vrapper/vrapper#854](https://github.com/vrapper/vrapper/issues/854)
**Severity:** MEDIUM (broken counted subword motions/text objects and EOF exception)

## Description

1. **Stale `fromPosition` in `SubwordMotion.doIt(EditorAdaptor, Position fromPosition, int toOffset)` (lines 80–96):**
   `doIt` constructs `Position cursor = editorAdaptor.getCursorService().newPositionForModelOffset(toOffset);`, yet line 96 calls:
   ```java
   Position dest = wordMotion.destination(editorAdaptor, fromPosition);
   ```
   Every caller that passes an updated `toOffset`—including `destination()` on `count > 1` (`2\w`, `2\e`, `2\b`), the `Limit.END` retry (`++toOffset` at line 71), and `SubwordTextObject.getRegion()` (`cursorOffset + 1` at line 193 and `endOffset` loop at lines 207–209)—still computes `dest` from the original `fromPosition`, preventing progression across outer word boundaries.
2. **Out-of-bounds read at EOF in `SubwordTextObject.getRegion()` (line 182):**
   ```java
   String startChars = cursorOffset > 0 ? model.getText(cursorOffset - 1, 2) : "";
   ```
   When `cursorOffset >= model.getTextLength()` (e.g., an empty last line), reading `2` characters from `cursorOffset - 1` exceeds document length and throws `VrapperPlatformException` (`BadLocationException`).

## Impact

- Counted subword motions/text objects (`2\w`, `2\e`, `2di\w`, etc.) fail across word boundaries, and invoking a subword text object on an empty last line throws an exception.

## Suggested fix

- Pass `cursor` instead of `fromPosition` to `wordMotion.destination(editorAdaptor, cursor)` inside `doIt()`.
- Guard line 182 so `cursorOffset > 0 && cursorOffset < model.getTextLength()` (and clamp `cursorOffset + 1` to `model.getTextLength()` at line 193).

**Status:** OPEN.
